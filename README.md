# vf-viewer

Browser code of the invoice viewer on https://visualizzarefatturaelettronica.com, built for the site from its
own source. Files are opened only in the visitor's browser; nothing is uploaded.

- `main.js` and `chunk-*.js`: the viewer (includes pkijs, asn1js and DOMPurify).
- `FoglioStileAssoSoftware.xsl`: the AssoSoftware stylesheet, unmodified. Property of AssoSoftware, distributed free of charge;
  see `XSL-SOURCE.md` for source and licence.
- The XSLT polyfill is loaded from https://cdn.jsdelivr.net/npm/xslt-polyfill@1.0.36/xslt-polyfill.min.js (BSD-3-Clause).
